# Karatas Family

> Contemporary Living, Philosophy & Digital Ecosystem

Karatas Family is an interconnected platform bringing together deep philosophical values (*Keimanan, Akhlak, Rasa Ingin Tahu, Ambisi, Tanggung Jawab, Amanah, Sustainability*), the Four Pillars (*Faith, Family, Freedom, Future*), and mindful digital sanctuaries including **K4Book**.

---

## 🚀 Features

- **Modern Editorial Landing Page**: Clean, contemporary typography and aesthetic layout built with Next.js App Router and Tailwind CSS v4.
- **Lenis Smooth Scroll**: Butter-smooth inertial momentum scrolling experience across all devices.
- **Continuous Ribbon Philosophy Deck**: Fluid, connected horizontal carousel with natural spring physics for the 7 core virtues.
- **K4Family Ecosystem Section**: Parallax stacking card architecture featuring upcoming modules (*K4Book*, *RANI AI*, *K4Craft*, *K4Studio*, *K4Farm*, *K4Health*, *K4Academy*, *WarunK*).
- **K4Book Sanctuary** (`/k4book`): Dedicated reading experience with 3D paper simulation, reading velocity tracking, customizable typography, and reader dashboard.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) 16 (App Router, Webpack engine)
- **UI & Styling**: [React](https://react.dev/) 19, [Tailwind CSS](https://tailwindcss.com/) v4
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Smooth Scrolling**: [Lenis](https://lenis.darkroom.engineering/)
- **Language**: TypeScript (Strict Mode)

---

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### 3. Production Build
```bash
npm run build
npm run start
```

## 🌐 Routes

- `/k4book/explore` — Book Discovery & Catalog
- `/k4book/book/[id]` — Book Detail & Chapter Reader
